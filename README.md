# AIBOX — المرحلة 1

## ما الموجود في هذه المرحلة
- مشروع Android Studio كامل (Kotlin) قابل للفتح والبناء.
- شاشة رئيسية: TikTok / Spotify / My Videos / Settings.
- **خدمة Floating Window حقيقية** تعمل عبر `WindowManager` + `SYSTEM_ALERT_WINDOW`:
  - سحب النافذة من الشريط العلوي.
  - تغيير الحجم من المقبض في الزاوية.
  - تصغير إلى أيقونة عائمة، والضغط عليها لإعادة الفتح.
  - حفظ آخر مكان وحجم (SharedPreferences).
  - زر إغلاق، وزر "Fullscreen" يفتح نفس الرابط في المتصفح الافتراضي.
- **My Videos**: اختيار فيديو من الجهاز، تشغيله، حذفه، بحث بالاسم. لا يحتاج أي حساب.
- **Settings**: طلب إذن النافذة العائمة + مكان مخصص لربط حساب Spotify.

## نقطة مهمة يجب فهمها
Android **لا يسمح** لتطبيق بأخذ تطبيق آخر مثبّت (تطبيق TikTok أو Spotify الرسمي)
وعرضه داخل نافذة عائمة يتحكم بها تطبيق ثالث — هذه ليست قدرة متاحة في نظام Android
للتطبيقات العادية (بدون root أو صلاحيات نظام خاصة).

لذلك AIBOX يفتح **الموقع الرسمي نفسه** (`tiktok.com` / `open.spotify.com`) داخل
WebView تابع لـ AIBOX، معروض كنافذة عائمة. هذا محتوى حقيقي 100%، وليس نسخة مقلّدة،
لكنه تقنيًا "متصفح مصغّر عائم" وليس "تطبيق TikTok نفسه محشور بالقوة داخل إطار".

## لماذا لا يوجد "فييد تصفح TikTok" مخصص بدون تسجيل دخول متصفح؟
لأن TikTok لا يوفر API رسمي لتصفح المحتوى العام (فييد كامل + بحث + تشغيل نتائج).
الـ Login Kit / Display API الرسمي يقتصر على فيديوهات حساب المستخدم نفسه فقط.
موقع tiktok.com عبر WebView هو أقرب بديل رسمي وقانوني.

## بناء APK من الموبايل بدون كمبيوتر (GitHub Actions - مجاني)

المشروع فيه الآن ملف `.github/workflows/android-build.yml` يبني الـ APK تلقائيًا
على سيرفرات GitHub كل ما ترفع كود. الخطوات كلها من متصفح الموبايل:

1. سوّي حساب مجاني على github.com (من متصفح الموبايل).
2. أنشئ Repository جديد فاضي بالاسم AIBOX (زر "New").
3. من داخل الـ Repository: "Add file" → "Upload files"، وارفع كل ملفات مجلد
   AIBOX (فك الضغط أولاً بأي تطبيق فك ضغط على الموبايل، ثم ارفع الملفات
   بما فيها مجلد `.github` كامل - أغلب متصفحات الموبايل تدعم اختيار مجلد كامل
   عند الرفع).
4. بعد الرفع، روح لتبويب "Actions" أعلى الصفحة - البناء يبدأ تلقائيًا خلال
   دقيقة أو دقيقتين.
5. لما تخلص العملية (علامة ✅ خضراء)، افتحها واضغط على "AIBOX-debug-apk"
   بالأسفل تحت "Artifacts" - راح يتحمل ملف مضغوط فيه الـ APK الجاهز.
6. فك الضغط، ثبّت الـ APK على موبايلك (فعّل "تثبيت من مصادر غير معروفة" إذا طلب منك).

هذه نسخة Debug (للتجربة، صالحة للتثبيت والتشغيل عادي). التوقيع بمفتاح رسمي
للنشر النهائي (Release) نسويه بمرحلة لاحقة.

### بديل: بناء مباشر على الموبايل نفسه (بدون إنترنت خارجي بعد التحميل الأول)
تطبيق **AIDE** (متوفر بمتجر Google Play) يقدر يفتح مشاريع Android Studio
ويبنيها مباشرة على الهاتف نفسه. الدعم الكامل لـ Kotlin فيه ميزة مدفوعة
بالنسخة المجانية من AIDE، فإذا تفضل خيار مجاني بالكامل، استخدم طريقة
GitHub Actions أعلاه.

### إذا صار عندك كمبيوتر لاحقًا (Android Studio)
1. افتح مجلد `AIBOX` في Android Studio (Hedgehog أو أحدث).
2. Android Studio سيولّد ملفات Gradle Wrapper تلقائيًا عند أول فتح (أو نفّذ `gradle wrapper` يدويًا إذا تستخدم Gradle من سطر الأوامر).
3. اضغط Run، أو من Terminal:
   ```
   ./gradlew assembleDebug
   ```
   الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## متطلبات الجهاز
- Android 8.0 (API 26) فما فوق (بسبب `TYPE_APPLICATION_OVERLAY`).
- عند أول استخدام لأي خدمة، سيطلب منك التطبيق إذن "الظهور فوق التطبيقات الأخرى" —
  هذا الإذن الذي يعوّض عن غياب ميزة النوافذ العائمة في واجهة ريلمي الخاصة بك.

## المرحلة القادمة (لم تُبنَ بعد)
- **Spotify SDK حقيقي (تحكم تشغيل/إيقاف/تالي/سابق فعلي بدل WebView)**:
  يتطلب منك إنشاء تطبيق في https://developer.spotify.com/dashboard والحصول على:
  - `Client ID`
  - `Redirect URI` (سجّله في نفس اللوحة، مثال: `aibox://callback`)
  ضع الـ Client ID في `gradle.properties` كـ `SPOTIFY_CLIENT_ID=...` ولا تضعه أبدًا
  مباشرة في الكود المرفوع لمستودع عام. لا يوجد Client Secret يُستخدم من الموبايل
  (نستخدم PKCE، الأكثر أمانًا للتطبيقات).
  ملاحظة: التحكم الفعلي بالتشغيل عبر SDK يتطلب أن يملك المستخدم حساب Spotify Premium
  (قيد مفروض من Spotify نفسها، وليس تصميمًا مني).
- Website (صفحة رئيسية + Download APK + سجل إصدارات + Privacy/Terms/Contact).
- Backend + API نشر APK محمي بمصادقة (لا يظهر مفتاح النشر في الواجهة الأمامية).
- توقيع APK للإصدار النهائي (keystore).

قل لي أي جزء تبي نبنيه بعدها وأكمل عليه بنفس الأسلوب (ملفات حقيقية كاملة، بدون اختصار).
